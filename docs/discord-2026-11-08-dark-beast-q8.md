**Krea 2 pack update (1.10.3): Dark Beast Q8 now gives you the real Q8**

If you installed the **Dark Beast Krea 2 (GGUF Q8)** card, you most likely got the Q4 file under the Q8 name: a 7.7 GB download instead of 14.6 GB. A store sync bug sent both GGUF cards to the same file. Sharmystic has fixed it on the store side, and sectorbob gets the credit for not letting it go. Thanks to both!

**What to do:** update the Krea 2 pack in the Community store. The Q8 card now uses a new file name, so the update downloads the real 14.6 GB Q8 for everyone, whether or not you had the wrong file.

**Free up space afterwards:** the app never deletes model files, so the old 7.7 GB file stays on your disk. Once the new one has downloaded, you can delete this file from your models\diffusion_models folder:
`darkBeastKrea2Aggressive_v10_q80.gguf`
Leave `darkBeastKrea2Aggressive_v10_q40.gguf` alone if you use the Q4 card, which was never affected.

**RedCraft Red Mix 1.1:** the author has made this file paid on Civitai, so new installs of that card fail. If you already have it, it keeps working. If you don't, use **RedCraft Krea 2 Red Mix 3.0** in the same pack. It's free, from the same author, and has a darker, more dramatic look.
