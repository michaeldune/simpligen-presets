# Discord update note: Qwen Image 2.1 1.3.0, Edit 4MP (POSTED by Michael 2026-09-22 18:29)

**Qwen Image 2.1 (1.3.0): Edit 4MP**

@sadpianonoises asked for a 4MP edit, so here it is: **Qwen Image 2.1 Edit 4MP**. It's the Edit card with the output at the model's full ~4 megapixels (2048 x 2048 square, 2752 x 1536 wide). Use 1 to 4 reference pictures, or cast up to 4 characters with the picker.

It runs on a 12 GB card: about 2 minutes with one picture and under 4 minutes with four. In testing every face held, even with four people; with four, a piece of clothing sometimes changes, so generate again with a new seed if it does.
