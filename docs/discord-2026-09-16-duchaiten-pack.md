:art: **New pack: DucHaiten** (9 cards)

DucHaiten's checkpoint family in one pack, each card set up the way the author publishes it: sampler, CFG, CLIP skip and the right VAE, so the first render looks like the model page.

- **GoldenLife 1.0**, **Retro 2.0**, **Real3D-NSFW 1.0**, **StyleLikeMe 1.5**, **ThiccBoi 1.0** on SD 1.5 (512-base, CLIP Skip 2, DPM++ 2M Karras; 2 to 2.4 GB each)
- **XL Golden-Age 1.0** on SDXL, golden-age illustration look
- **NoobAI-Cinematic 1.0** plain, and a **Snapvu** card that adds a 4x-UltraSharpV2 hires pass for the pore-level version
- **GameArt UnrealEngine 1.0** on Pony, game-render style (`score_9, score_8_up` tags help)

Full pack is about 42 GB across nine checkpoints; install one card at a time if you only want a style or two. ThiccBoi is the same checkpoint the SD 1.5 Anime pack already ships, so it downloads nothing extra if you have that.

Civitai hosts every checkpoint, so the installer will ask for your free Civitai API token. Store picks it up on its next sync.
